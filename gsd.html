        ℹ️ About GSD

        What “GSD” means

        GSD = Getting Stuff Done. A single, offline, self-contained to-do app built around the Getting Things Done (GTD) productivity framework. Instead of a flat list, it lets you work tasks by their attributes — priority, due date, size and category — so the right thing rises to the top.

        (Read the “S” however colourfully you like — that’s on you. 😏)

        Terms used in the app

        • Priority — High · Medium · Low. Sets the coloured left border and the tinted •dot chip.
        • Category — an identity pill: a managed category, a custom value, or none.
        • Size — effort estimate xs–xl, shown as a grey badge. Smaller = a quick-win nudge in Smart sort.
        • Due date — optional. The 📅 chip turns amber within 2 days and red once overdue.
        • Awaiting — a deferred / waiting-on state with a note and a bring-back date; the task auto-returns to the list on that date (⏳ to defer, ↩ to pull back now).
        • Done — completed; shown dimmed with a strikethrough and sunk to the bottom.
        • Smart score — the number behind ✨ Smart sort (see below).

        Features

        • Add — the floating + button opens a right-side pane with the task fields.
        • Edit / delete — click any row to reopen that pane pre-filled; edit, toggle done, or delete.
        • Duplicate — hover a row and click ⧉ to clone it as “copy of - …”.
        • Awaiting — hover a row and click ⏳ to defer with a note + bring-back date; it returns automatically.
        • Categories — the hamburger → 🗂 Categories pane adds / renames / deletes categories (CRUD).
        • Search · filter · sort — search text; filter by status / category / priority; sort by Smart, Due, Priority, Size, Category or Created.
        • Auto-save — every change writes straight to your data-gsd/ folder (to-do / done / categories JSON files), with a localStorage backup.
        • Unsaved-changes guard — closing the editor with pending edits prompts before discarding.

        The GTD-style Smart score

        ✨ Smart (auto) ranks tasks by a computed score — higher sorts first. It blends three things and never changes your manual priority. Done tasks always sink; ties break by the earliest due date.

        score = priority + size (quick-win) + urgency

        Priority points

        High+40
        Medium+20
        Low+5

        Size points (smaller = quick-win boost)

        xs+12
        s+9
        m+6
        l+4
        xl+2

        Urgency points (from the due date)

        Overdue+60, +1 / extra day (max +100)
        Due today+55
        Within 2 days+45
        Within a week+30
        Within 2 weeks+20
        Later+10
        No due date+10

        Data & privacy

        Everything lives locally — in a data-gsd/ folder you choose on first launch and in your browser. Nothing is sent anywhere. Live folder auto-save needs Chrome or Edge; Safari / Firefox fall back to in-browser storage with manual export.

        The folder is schema-versioned (meta.json): point the app at an older data folder and it auto-upgrades it to the latest format on load — snapshotting a backup zip into data-gsd/backups/ first, so nothing is lost.
